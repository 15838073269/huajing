# Blender AI Image Generation Plugin

这是一个基于原有Web AI生图插件转换而来的Blender插件，支持文生图和图生图功能，与Blender的图像编辑器深度集成。

## 🎯 主要功能

- **文生图（Text-to-Image）** - 通过文本提示生成图像
- **图生图（Image-to-Image）** - 基于现有图像进行AI生成
- **实时预览** - 生成过程中的状态显示
- **历史记录** - 自动保存生成历史和参数
- **多种分辨率** - 支持从1K到4K的多种预设和自定义分辨率
- **格式支持** - 支持PNG、JPEG、WebP格式输出

## 📋 系统要求

- Blender 3.0+
- Python 3.7+
- requests库（通常Blender已内置）
- 有效的GPT-Image API密钥

## 🔧 安装方法

1. **下载插件文件**
   - 将整个`blender_ai_image_gen`文件夹复制到Blender的插件目录
   - 或者压缩为`.zip`文件通过Blender界面安装

2. **在Blender中启用插件**
   - 打开Blender
   - 转到 `Edit > Preferences > Add-ons`
   - 点击 `Install...` 选择插件文件
   - 勾选启用插件

3. **配置API密钥**
   - 在插件偏好设置中配置GPT-Image API密钥
   - 设置API基础URL（默认为GPT-Image官方API）

## 🎮 使用方法

### 基本使用

1. **打开图像编辑器**
   - 切换到Image Editor视图
   - 在右侧面板中找到 "AI Gen" 标签

2. **文生图**
   - 选择 "Text to Image" 模式
   - 在提示词框中输入描述
   - 设置分辨率、质量等参数
   - 点击 "Generate" 开始生成

3. **图生图**
   - 选择 "Image to Image" 模式
   - 在图像编辑器中打开或创建参考图像
   - 勾选 "Use Active Image" 
   - 输入提示词描述要修改的内容
   - 点击 "Generate" 开始生成

### 高级功能

**历史记录**
- 在 History 面板中查看所有生成历史
- 点击 "Use Prompt" 快速重用历史提示词
- 使用 "Clear" 按钮清除历史记录

**提示词模板**
- 在 Templates 面板中使用预设模板
- 快速插入常用的提示词组合

**自定义设置**
- 在偏好设置中配置默认参数
- 设置历史记录保存数量限制
- 切换高级选项显示

## ⚙️ 参数说明

### 生成参数

- **Mode**: 生成模式（文生图/图生图）
- **Prompt**: 文本提示词，描述要生成的内容
- **Resolution**: 输出图像分辨率
  - Preset: 预设分辨率选项
  - Custom: 自定义宽度和高度
- **Model**: AI模型选择（目前支持GPT-Image-2）
- **Quality**: 生成质量
  - Auto: 自动选择
  - Low: 低质量，生成速度快
  - Medium: 中等质量，平衡速度和效果
  - High: 高质量，生成速度慢
- **Format**: 输出格式（PNG/JPEG/WebP）
- **Number of Images**: 一次生成的图像数量（1-4张）

### 分辨率限制

根据GPT-Image API要求：
- 最大边长不超过3840像素
- 长宽比不超过3:1
- 总像素在655360~8294400之间
- 宽度和高度必须为16的倍数

## 🔗 API配置

### 获取API密钥

1. 访问GPT-Image API提供商网站
2. 注册账户并获取API密钥
3. 在Blender插件偏好设置中配置

### API端点

- **文生图**: `POST /v1/images/generations`
- **图生图**: `POST /v1/images/edits`

## 📝 注意事项

1. **API限制**: 使用时请遵守API提供商的使用限制和条款
2. **网络连接**: 需要稳定的网络连接进行API调用
3. **生成时间**: 图像生成可能需要几分钟时间，请耐心等待
4. **图像质量**: 生成结果受提示词质量和AI模型限制
5. **版权声明**: 生成的图像版权归AI服务提供商所有，使用时请注意版权问题

## 🐛 故障排除

### 常见问题

**Q: 生成失败，显示API错误**
A: 检查API密钥是否正确，网络连接是否正常

**Q: 无法选择活动图像**
A: 确保在图像编辑器中有打开的图像，并且处于活动状态

**Q: 历史记录没有保存**
A: 检查偏好设置中的 "Auto-save History" 是否启用

**Q: 生成按钮是灰色的**
A: 确保已输入提示词，并且没有在生成过程中

### 获取帮助

如果遇到问题，可以：
1. 检查Blender系统控制台输出的错误信息
2. 验证API密钥和网络连接
3. 尝试使用更简单的提示词
4. 减小生成分辨率和图像数量

## 🚀 性能优化

- **减小分辨率**: 使用较低的分辨率可以显著减少生成时间
- **减少图像数量**: 一次生成较少的图像
- **使用低质量模式**: 在测试阶段使用Low质量快速预览
- **优化提示词**: 使用简洁明确的提示词可以获得更好的结果
